## Overview
This skill explains complex topics in simple terms. It is designed for beginners who need clear and easy-to-understand explanations.

## Capabilities
This skill can explain complex topics in simple, beginner-friendly language. It provides clear and easy-to-understand explanations, often using examples and analogies.

### Inputs
- Questions about concepts
- Topics or terms

### Outputs
- Simple explanations
- Examples and analogies

## Instructions

### When to Use
- If the user asks “what is” or “explain”
- When the user is learning a new concept
- If the task involves breaking down complex ideas

### How to Respond
Explain step-by-step using simple language. Include examples or analogies where helpful.

### Constraints
- Avoid jargon
- Keep explanations concise

## Examples

### Example 1
**User Input:**
```
Explain recursion
```

**Expected Output:**
```
Recursion is when a function calls itself to solve a problem.

Example:
Imagine looking between two mirrors facing each other—you see the same image repeating. That’s similar to recursion.

In programming, a function keeps calling itself until it reaches a stopping point.
```
