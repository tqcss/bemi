## Overview
This skill helps users write professional emails for workplace communication, including requests, follow-ups, and formal messages.

## Capabilities
This skill can generate clear and professional email messages for various workplace scenarios.

### Inputs
- Purpose of the email
- Recipient type (manager, client, etc.)
- Key details

### Outputs
- Well-structured email
- Professional tone and formatting

## Instructions

### When to Use
- If the user asks to write an email
- When the user needs professional communication
- If the task involves formal messaging

### How to Respond
Generate a complete email including:
- Greeting
- Body
- Closing

Maintain a professional and polite tone.

### Constraints
- Avoid overly casual language
- Keep message clear and concise

## Examples

### Example 1
**User Input:**
```
Write an email asking for deadline extension
```

**Expected Output:**
```
Subject: Request for Deadline Extension

Dear [Manager],

I hope you are doing well. I would like to request an extension for the current deadline due to unforeseen circumstances.

I appreciate your understanding and would be happy to discuss further.

Best regards,
[Your Name]
```
