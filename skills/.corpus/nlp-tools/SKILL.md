# NLP Text Processing Skill

This skill provides natural language processing utilities for text analysis and manipulation.

## Functions Available
- Text tokenization and segmentation
- Sentiment analysis
- Named entity recognition
- Text summarization
- Language detection

## Usage Examples
- Analyze sentiment of text
- Extract named entities from documents
- Summarize long articles
- Detect language of text
- Tokenize sentences and words

## Dependencies
- nltk for natural language processing
- spacy for advanced NLP tasks
- transformers for modern language models
- textblob for simple sentiment analysis
